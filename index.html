How to play

A quick guide to the combined adaptive n-back task.

01 / Learn the mapping
Open Settings and memorize each emotional face's assigned number. The mapping stays hidden during a session so you must retrieve it from memory.
02 / Combine values across time
At each turn, mentally combine the current face's number with the face shown N steps earlier. Apply the operation shown on screen (for example, current − N-back, using the absolute difference). Enter the non-negative integer result before the next stimulus. A correct answer submits automatically.
03 / Adapt as you go
With Variable N enabled, the N level can shift from turn to turn. Correct and incorrect streaks automatically change the stimulus interval within your configured bounds. An unanswered turn counts as incorrect.
04 / Feedback
Submit with Enter or the button. Immediate feedback shows whether the answer was correct and reveals the expected result after an error. Session metrics track accuracy and streaks.
